# Meeting Minutes

Toplantı notlarını düzenli, erişilebilir ve takip edilebilir şekilde saklamak için kullanılan depo.

## İçerik

- Toplantı tarihleri ve katılımcılar
- Gündem maddeleri
- Alınan kararlar
- Aksiyonlar ve sorumlular
- Takip notları

## Toplantı Notu Şablonu

Her toplantı için aşağıdaki başlıkları kullanabilirsiniz:

```markdown
# Toplantı Başlığı

- **Tarih:** YYYY-AA-GG
- **Katılımcılar:**
- **Toplantı sahibi:**

## Gündem

1. 

## Görüşülen Konular

- 

## Alınan Kararlar

- 

## Aksiyonlar

| Aksiyon | Sorumlu | Son tarih | Durum |
| --- | --- | --- | --- |
|  |  |  |  |

## Sonraki Toplantı

- **Tarih:**
- **Gündem:**
```

## Katkıda Bulunma

Yeni toplantı notlarını uygun klasöre ekleyebilir veya mevcut notlarda düzeltme yapabilirsiniz.
